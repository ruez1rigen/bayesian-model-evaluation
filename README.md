# bayesian-model-evaluation 📈🧐

*"Accuracy will not give the correct picture always."*

This repository implements a Bayesian framework for evaluating Machine Learning models, providing insights into the confidence and reliability of model predictions.

## 🧠 Why Bayesian?
- **Uncertainty Quantification**: Understanding what the model *doesn't* know.
- **Small Data Robustness**: Better evaluation for cases where test data is limited.
- **Probabilistic Insights**: Moving from binary classification to probability distributions.
